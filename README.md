==================================================
1. MOST IMPORTANT DESIGN CONCEPT
==================================================

The primary visual experience of POLARSETU is:

"EXPLORE POLAR SCIENCE AS A LIVING 3D LANDSCAPE."

The homepage should feel like a cinematic interactive Arctic/Antarctic environment.

Imagine the experience as a combination of:

- cinematic polar expedition
- scientific museum
- interactive knowledge graph
- modern AI interface
- scientific visualization
- immersive 3D landscape
- educational exploration platform

Do NOT make it look like:

- a generic SaaS dashboard
- a generic AI chatbot
- a social media clone
- a gaming website
- a childish educational website
- a generic 3D portfolio website

The experience should communicate:

SCIENCE + EXPLORATION + TRUST + DISCOVERY + TECHNOLOGY

==================================================
2. TECHNOLOGY STACK
==================================================

Use a modern production-ready stack.

FRONTEND:

- React
- TypeScript
- Vite or Next.js
- Tailwind CSS
- shadcn/ui
- Lucide icons
- Framer Motion
- GSAP where required

3D:

- Three.js
- React Three Fiber
- @react-three/drei
- WebGL
- optimized particle systems
- scroll-driven camera animation

BACKEND:

Prefer:

- Supabase
- PostgreSQL
- Supabase Auth
- Supabase Storage
- Row Level Security
- server/edge functions

If the environment provides another native backend, use it while preserving the same architecture.

AI:

Create an AI abstraction layer.

Architecture:

Frontend
→ Backend API
→ AI Service
→ Retrieval Layer
→ Knowledge Database
→ LLM
→ Citation System

Do not tightly couple the application to a single AI provider.

SEARCH:

Use PostgreSQL full-text search initially.

Architecture should allow vector/semantic search later.
